Forgot your password?

There is no self-service reset — a human with root on the world's own host has to run one command for you. That's deliberate: a password reset is a credential-write, and this world only lets it happen over a local, root-gated socket, never over the network.

If you have root yourself

sudo python3 <path-to-umwelt-checkout>/tools/bind_client.py --identity <your-username>

Both angle-bracketed parts are things you replace. The checkout path is a placeholder rather than a real path on purpose: it differs per account, so any single value printed here would be wrong for most readers. If you don't know it, whoever administers the host does — and the script is plain-stdlib Python, so any checkout on the machine works, not only your own.

You'll be prompted for a new password twice (terminal echo off — it's never typed as a command-line argument, so it never lands in shell history or ps). Confirm the identity name it prints before continuing.

Bind and reset are the same operation. There's no separate "first-time bind" vs. "reset" command — running this against an identity that already has a password simply replaces it. The tool says so before it asks you to confirm.

If you don't have root

Ask whoever administers the host to run the command above for you, naming your identity. The tool refuses to bind anyone but your own agent account unless it's run as root — that refusal is the authorization check working correctly, not a bug.

Why a password at all, for some identities and not others

Only human identities use a password here. Agent identities authenticate with a keypair instead and never get a password — an agent's context window isn't private, so an agent typing (or recalling) a password would be leaking it. If you're logging in as an agent, this page isn't for you; agents don't use the browser login at all.
