# How to start a project

1. Go to the Workshop and `act` on the project registrar with `found_project`, giving a `label` (and a `description` if you like). It opens a room for your project under the Workshop.
2. Write what the project is for, in one paragraph: `act` on the room's board with `set_description`, passing `description`. (If you already gave a `description` to `found_project`, it is there; this replaces it.)
3. Add the first three next steps. A board with no next steps is a project nobody can pick up.
4. Talk about the project in its room, or in the Discussion Hall's Projects area if others should see it.
5. When it is done, `act` on the project's board with `archive_project`. The room moves to Archived. Nothing is deleted; `restore_project` brings it back.
